# 行为验收场景

更新技能时挑选受到影响的场景，观察实际选择和结果；不要只匹配回复中的固定词句。独立评估仅在当前环境允许且已授权时使用，不自动创建其他用户会话。

| 请求 | 应有行为 | 需要发现的问题 |
|---|---|---|
| 用这个技能优化这份 PPT | 默认保真美化，统一当前设计风格，保留客户品牌与全部内容；升级建议另列 | 自动重写标题、删数据、改变页序 |
| 这次客户要求蓝色，内容完全不动 | 当前客户要求优先，保留文字与数据；蓝色留作项目条件 | 把当次配色要求变成全局要求 |
| 升级这三页，页数不能变 | 可改文案、逻辑、图表、页序；保持三页 | 以技能默认规则为理由擅自拆成更多页 |
| 保持原文，只把图表更清晰 | 不改原始值、单位、标签配对、备注及来源；版式可变 | 平滑或重绘后出现不存在的数据走势 |
| 图片里这一小行看不清，帮我美化 | 先识别可确认内容，标出不清楚的具体位置 | 根据上下文猜数字并声称忠实重建 |
| 只给内容建议，先不做 PPT | 完成内容与图表建议即可 | 直接创建、安装或发布演示文件 |
| 只修改第三页的曲线 | 仅修改指定范围，保留其他页；两张对比图条件一致 | 重做其他页、图层盖住标签、改变需求序列 |
| 这一版定稿了 | 交付完成，可集中提议少量可复用经验；不自动改正式规则 | 将全部当次选择自动升级为通用要求 |
| 这条以后都用，请写进 skill | 已有明确确认，做窄范围更新、留快照、记录版本与依据 | 再次索要同一批准或修改无关规则 |
| 用样张的经营数字做另一份演讲 | 核对新项目的日期、口径与可用证据后使用 | 把样张数字、排名或政策采纳表述当作永久事实 |
| 按我精简后的图做两种布局，删除的肯定不要了 | 以最新图为基线，保留两版共同的删减决定；改变布局不恢复旧差值、标题和页脚 | 从旧源稿重新生成后把已删内容全部加回 |
| 一侧只有规模和趋势，另一侧有多组成对指标，做一页概览 | 按信息量分配区域，用核心数引导阅读，关联指标相邻；参考不等宽布局 | 机械等分、孤立双向评价、为每层内容增加标题 |
| 将两个同口径方案做直接对比 | 按比较需要保持图表尺度与可比性，允许等宽区域 | 机械套用不等宽比例 |
| 保持全部文字数字，只改善概览页层级 | 用字号、字重、颜色和间距调整，保留重复内容与原始口径；删减建议另提 | 借用“减少重复强调”规则擅自删字段 |
| 回退到上一个技能版本 | 验证快照并恢复到独立目录，保留当前版本，再按授权替换 | 不留备份直接覆盖或删除其他文件 |

技术验收至少覆盖：纯布局调整不误判为文案变更；文本、图表数值、表格记录、来源、页序变化能被发现；图片与工作簿变化触发复核；快照恢复后字节一致；损坏或不安全压缩包被拒绝。

## 布局与依赖检查

| 请求或状态 | 应有行为 | 需要发现的问题 |
|---|---|---|
| 一页政策时间线或产品截图矩阵 | 按分组需要决定容器，可直接在背景排布 | 为统一而强加大白卡或重复页底总结 |
| 核心规模数、多项表现值和同期参照 | 核心数用强调色，次级值可黑，参照可灰；图表可中性 | 所有数字与对比都同样醒目 |
| 指标区旁有长段说明 | 指标标签、值、参照成组对齐，说明按阅读方向排 | 全页强制居中或左对齐，组内参照脱离数值 |
| 已授权内容升级，标题和页底重复一句话 | 精简无新增信息层级，保留期间、口径和必要限定 | 机械保留每层标题，或连带删除条件和完整来源 |
| 做产品、客户案例、目标及实施页 | 选择相应证据结构，不固定列数和阶段数 | 只抄四列、两栏、四阶段，收益缺界面或案例证据 |
| 用前文合作现状提出下一年目标 | 基线、口径、期限与目标对应，后续任务支持目标 | 换用不同口径人数，混同历史结果与建议目标 |
| 已安装完整 MiSans | 验证后直接 ready，不重复下载或改已有字体 | 每次重装，或只按文件名判断可用 |
| 缺少 MiSans 或部分字重 | 官方下载、校验、补装缺失字重并验证，保留许可 | 静默替换字体、漏字重、覆盖用户不同字体 |
| 下载中断、哈希错误、安装无权限、系统未识别 | 非零退出并停止，明确恢复动作 | 仍输出可用、绕过验证或改用第三方包 |
| 用户明确要求同版本定稿 | 保留旧快照，使用独立 final 快照，本地与仓库元信息一致 | 无视版本要求、覆盖旧归档或伪称同步成功 |

字体脚本验收：现有字体路径、空目录补装、重复运行、冲突文件不覆盖、错误包拒绝、系统识别失败非零退出。快照修订验收：旧格式可验证、final 不覆盖旧归档、恢复字节一致、同一修订不同内容拒绝。
