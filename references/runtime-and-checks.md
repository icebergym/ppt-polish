# 制作与检查

## 环境与目的地

使用此技能前必须先按 [字体安装与验证](font-setup.md) 运行 `scripts/ensure_misans.py`。字体未就绪时停止；返回成功后，在实际作者工具核对 MiSans 的可用字体与字重映射，检查文本框、表格和图表，不能只检查系统目录。

先遵循本次用户指定的目的地及当前运行环境的演示文稿路由。可用时发现并调用 `load_workspace_dependencies`，动态取得运行时与库位置；读取当前可用的演示文稿技能，不固化机器用户名、缓存版本或特定 API 路径。

已有在线文档在绑定文档中修改；本地文件先导入当前素材。缺少在线连接而允许本地交付时使用环境支持的 PPTX 作者工具。这里提供设计与内容规则，不替代宿主工具的权限和导出规范。

默认完成可编辑演示稿及预览；用户只要内容时不生成幻灯片。只改指定页或选区，其他页保持原样。保留原稿与当前版本，文件名清楚区分。

## 可编辑实现与已知问题

- 图表、表格和文字优先用原生对象，真实照片及产品界面保持原图。
- 机制曲线需要圆滑时，先查原生平滑支持。面积图不支持曲线平滑时，可以明确标注为示意并使用密集连续采样；这不是对实测数据的补造。对比图共用同一需求序列和尺度。
- 导入再导出可能丢失图表工作簿或关系。复用已有图表时保存原始工作簿与来源，检查关联；新建的纯示意数据可建立明确标识的字面值工作簿快照，不能伪造公式来源。
- 图表创建或替换后检查图层，保证标签在可见位置且不盖住关键曲线；再次查看真正导出的文件。
- 字体、图表、表格有各自的字体设置，不能只改文本框。核对中文缺字、单位、上下标及特殊符号。
- 不用重复的空类别填满稠密曲线，某些渲染器会合并相同类别导致错误连线。用唯一时间或索引保留类别，按工具能力显示必要时段标注。
- 原生图表的堆叠、零值、图例和轴位置必须检查渲染；不要把预览异常当成用户需要理解的业务结果。

## 内容锁定脚本

两个命令均用可用的 Python 3，脚本只用标准库：

```text
python scripts/content_guard.py snapshot 原稿.pptx before.json
python scripts/content_guard.py snapshot 修改稿.pptx after.json
python scripts/content_guard.py compare before.json after.json --report comparison.json
```

内容升级只允许某些页改内容时，可加 `--allow-content-on 3,5`；其他页仍按保真比较。不要在保真任务中用它掩盖文字变化。比较检查按页面对应的位置，页数变化始终单独报告。

检查覆盖：原生文本、表格、图表的类别与数值、图表及坐标标题、备注、链接。样式不参与内容比较；图片字节、裁切和不透明对象变化会触发人工复核。折行或拆框可能产生保守差异，需要逐项核对，不擅自忽略。

脚本不读取图片中的字、不重新计算工作簿公式，不证明讲述逻辑、数据来源或所有特殊图表均正确。PDF 与截图重建必须另建内容清单并逐页对照。

## 交付检查

1. 明确页数、改动范围与内容覆盖。
2. 对照来源核验事实、条件、数据单位、统计口径和引用。
   客户合作提案还要跨页核对：现状和目标是否同口径、案例成绩是否被误写成本客户成绩、目标是否有对应实施任务。近似值仍保留约数标记。
3. 逐页检查视觉：标题、换行、留白、裁切、遮挡、曲线与标注、图表尺度。
4. 运行当前制作工具的文件完整性、布局、字体、原生图表/工作簿检查。
5. 保真模式运行内容比较；升级模式检查被授权的差异和未改页。
6. 打开导出的结果重新渲染，确认交付文件与预览一致。没有打开 PowerPoint 本体就不宣称做过原生 PowerPoint 检查。

通过检查后交付，不为例行验证无限重复运行。只有新修改、失败或未解决的问题才继续检查。
